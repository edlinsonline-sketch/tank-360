# Free 6-frame 360° viewer

This folder contains a self-contained 360-style viewer using six JPG frames.

## Test it
Open `index.html` in a browser. Drag the object left/right.

## Put it online for free with GitHub Pages
1. Create a new **public** GitHub repository, e.g. `tank-360`.
2. Upload everything in this folder (`index.html` and `frame-1.jpg` through `frame-6.jpg`).
3. In the repository, open **Settings → Pages**.
4. Under the publishing source, choose the `main` branch and `/ (root)`.
5. Save. GitHub will give you a `github.io` address.
6. Use that URL as the link from your FlipHTML5 catalogue.

GitHub Pages supports static HTML/CSS/JavaScript files and is available with GitHub Free for public repositories.

Note: the six frames in this starter pack were extracted from the generated six-view contact sheet, so they are a practical prototype. For a high-accuracy catalogue spin, use six original photographs of the same object taken at evenly spaced angles.
